# Showcase — CRM Comercial Fullstack

## O que este projeto mostra

Demo pública e autônoma para apresentar clientes, produtos e propostas em um fluxo comercial completo.

## Status desta rodada

- Validado em 26/07/2026: testes, lint, build e auditoria de dependências
- Demo pública: https://crm-comercial-fullstack.vercel.app
- GitHub: https://github.com/Beckerr11/crm-comercial-fullstack
- Limite: não há backend ou banco remoto; os dados ficam no `localStorage`.

## Materiais desta pasta

- `video-script.md` - roteiro curto de apresentação
- `scenes.md` - ordem de cenas para gravação
- `captions.md` - textos de apoio para vídeo, reels ou post
- `screenshots/crm-desktop.png` — painel em 1440 × 900
- `screenshots/crm-mobile.png` — painel em 390 × 844

## Como usar

1. Rode a demo local ou abra a implantação pública.
2. Siga o roteiro de vídeo.
3. Use as capturas versionadas como referência do SHA validado.
4. Grave o vídeo somente quando existir um arquivo ou link público verificável.
